# AP Computer Science Prep Exam Repository
This repository serves as a comprehensive study tool and reference guide for students preparing for the AP Computer Science Principles exam. It is designed to bridge the gap between theoretical concepts and practical implementation

# Reference Materials
The reference-sheets directory contains detailed guides and examples to help you master core exam competencies, including:

- **Number Systems & Conversions:** Step-by-step documentation for converting between Binary and Decimal numbering systems.

- **Pseudocode Translation:** Comparative examples to help you fluently translate College Board Pseudocode into executable Python code.
